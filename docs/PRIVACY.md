# Приватность FrameTrail

Применяется к версии 1.0.0-beta.1. Дата: 22 октября 2026 года.

FrameTrail не использует собственный сервер аккаунтов, аналитические SDK, рекламные SDK или облачный сервис генерации. Приложение обращается непосредственно к поставщикам каталога и материалов. Поиск и авторизация требуют сети; обсуждение подготовленных материалов выполняется системной моделью Apple на устройстве. Для русского ответа при отсутствии прямой поддержки у модели используется локальный системный перевод Apple Translation.

## Что остаётся на устройстве

В библиотеке хранятся выбранные произведения, просмотренные серии, завершение фильмов, полученные и импортированные тексты, вопросы и ответы, оценки и личные итоги. Гостю и каждому TMDB-аккаунту соответствует отдельный файл в контейнере приложения. Разделение библиотек не является отдельной блокировкой Face ID и не заменяет защиту разблокированного устройства.

Библиотеки записываются атомарно. На iOS используется системная защита файлов до первого разблокирования после перезапуска. Это обычные JSON-файлы внутри защищаемого системой контейнера; отдельного пароля или собственного шифрования библиотеки нет. Системные резервные копии устройства могут включать данные приложения в соответствии с настройками iOS.

Для ответа приложение передаёт локальной модели ограниченный набор разрешённых материалов, текущий вопрос и несколько предыдущих вопросов. Если нужен перевод русского вопроса и английского ответа, этот текст обрабатывает Apple Translation на устройстве с подготовленными языковыми пакетами. Диалог и импортированные тексты не отправляются в облачный сервис генерации или удалённый сервис перевода. Настройки Apple Intelligence, установка и обновление системной модели и пакетов перевода контролируются iOS и Apple; загрузка пакетов требует сети и отличается от обработки текста.

Согласно [документации Apple TranslationSession](https://developer.apple.com/documentation/translation/translationsession), Apple может собирать метрики использования API и производительности, включая bundle ID приложения и языковую пару, без исходного и переведённого текста. Отсутствие встроенного аналитического SDK FrameTrail не означает отключение системных механизмов Apple.

## Какие сетевые запросы выполняются

| Получатель | Когда | Передаваемые данные |
| --- | --- | --- |
| TVmaze: `api.tvmaze.com`, изображения `static.tvmaze.com` | Обзор, поиск сериалов, список серий, показ постеров | Поисковая строка, идентификатор произведения или изображения, обычные параметры HTTP-запроса. |
| Wikidata: `www.wikidata.org` | Поиск фильмов без TMDB-токена, получение кратких сведений | Поисковая строка, язык поиска, идентификаторы найденных сущностей и параметры запроса; изображения из Wikidata не загружаются. |
| TMDB: `api.themoviedb.org`, `www.themoviedb.org`, `image.tmdb.org` | После подключения токена: каталог, постеры, авторизация, импорт watchlist | Поиск, идентификаторы фильмов/сериалов/аккаунта, API Read Access Token и, для операций аккаунта, идентификатор сессии. |
| Wikimedia: `en.wikipedia.org` | Только при явной загрузке сюжета завершённого фильма или открытии источника | Название фильма, возможный год, идентификатор статьи/раздела/редакции. |
| Системные службы Apple | Подготовка и обновление модели и языковых пакетов | Системные запросы установки соответствующих компонентов; загрузками управляет iOS. После подготовки перевод текста выполняется локально. |
| GitHub | Когда вы открываете исходники, Releases или Issues | Данные обычного посещения сайта; текст сообщения, если вы сами его публикуете. |

Сервисы получают IP-адрес и технические параметры соединения. Для API-запросов FrameTrail указывает свой User-Agent. Запросы API идут по HTTPS. Наличие HTTPS не скрывает содержимое запроса от его получателя. Сессия TMDB передаётся также в параметрах некоторых запросов к API; не публикуйте сетевые трассы без удаления секретов.

Ни поисковая строка, ни название выбранного фильма не являются полной копией вашего диалога. Приложение не использует текст обсуждения для запросов к стороннему поисковому или языковому сервису. При открытии ссылки в браузере действуют правила и возможные cookies соответствующего сайта.

Политики провайдеров: [TVmaze](https://www.tvmaze.com/site/privacy), [TMDB](https://www.themoviedb.org/privacy-policy), [Apple](https://www.apple.com/legal/privacy/), [Wikimedia](https://foundation.wikimedia.org/wiki/Policy:Privacy_policy), [GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Авторизация и секреты

Пароль TMDB вводится на сайте провайдера в системном браузерном представлении. FrameTrail получает подтверждённую сессию и сведения аккаунта, а не пароль.

API Read Access Token, идентификатор сессии и сохранённые сведения аккаунта находятся в Keychain с доступом на разблокированном устройстве и пометкой `ThisDeviceOnly`. Они не входят в JSON-экспорт библиотеки. При смене API-токена прежняя сессия завершается. Выход очищает локальную сессию и пытается отозвать её на TMDB. Если сетевой отзыв не удался, приложение сообщает об этом; при необходимости завершите сессию в настройках TMDB.

Выход не удаляет сохранённую библиотеку аккаунта и не удаляет автоматически API-токен, позволяющий искать в расширенном каталоге. Для удаления токена используйте соответствующую кнопку в настройках. Переподпись с другой идентичностью приложения может изменить доступ к Keychain; это зависит от способа установки.

## Импорт, экспорт и удаление

Импорт файла выполняется после выбора в системном окне. Приложение читает выбранный текст или JSON и не получает постоянного доступа ко всем файлам. Материал сохраняется в текущей библиотеке. Импортированная JSON-копия объединяется с текущими записями по времени изменения; исходный файл автоматически не удаляется.

Экспорт — **обычный незашифрованный JSON-файл**, содержащий произведения, тексты, прогресс, диалоги и личные записи текущей библиотеки. Он не содержит Keychain-секретов. Вы выбираете место сохранения и дальнейшее распространение файла; облачная папка, почта или общий доступ могут сделать его доступным другим людям.

Удаление произведения из библиотеки удаляет его локальные записи. Очистка материалов удаляет сохранённые списки серий и тексты, включая ваши импортированные источники, сохраняя прогресс, диалоги и итоги. Удаление приложения удаляет его контейнер в соответствии с поведением iOS; отдельно сохранённые экспорты и записи Keychain могут сохраниться. Для полного удаления секретов сначала выйдите из аккаунта и удалите токен, затем удалите ненужные экспорты и приложение.

В приложении нет автоматической отправки отчётов о сбоях разработчику. Если вы прикладываете библиотеку, скриншот или журнал к GitHub Issue, проверьте его содержимое самостоятельно: публикация Issue является отдельным действием и может раскрыть личные записи.
