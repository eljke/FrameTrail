## The Movie Database — TMDB

Приложение по выбору пользователя обращается к [TMDB](https://www.themoviedb.org) за метаданными, описаниями, постерами, списками серий и watchlist. Использование регулируют [условия API](https://www.themoviedb.org/api-terms-of-use) и [требования атрибуции](https://developer.themoviedb.org/docs/faq). Бесплатный developer API предназначен для некоммерческого использования с атрибуцией; коммерческое использование требует соответствующих условий TMDB.

> This product uses the TMDB API but is not endorsed or certified by TMDB.

## TVmaze

[Публичный API TVmaze](https://www.tvmaze.com/api) предоставляет сведения о сериалах, эпизодах, аннотации и изображения. Указанная API лицензия — [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Источником следует указывать **TVmaze**; ссылки на исходные страницы сохраняются в карточках произведений и серий.

Приложение преобразует HTML-аннотации в обычный текст, удаляет разметку и может выбирать или сокращать фрагменты для контекста. Эти изменения не переводят текст под MIT: применимые требования атрибуции и ShareAlike сохраняются для материалов и их адаптаций. При распространении выгрузок, включающих такие тексты, сохраняйте сведения об источнике и лицензии. Права на изображения и связанные объекты также необходимо учитывать отдельно.

## Wikipedia и Wikimedia

При явной загрузке сюжета используется раздел статьи **англоязычной Wikipedia**, созданной её участниками. Текст доступен на условиях [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) с учётом [условий Wikimedia](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) и указаний конкретной страницы.

FrameTrail удаляет HTML-разметку и номера сносок, ограничивает длину и разбивает раздел на фрагменты. С каждым загруженным фрагментом сохраняется ссылка на использованную редакцию статьи (`oldid`), позволяющая найти исходный текст и историю авторства. Это сокращённые или преобразованные материалы Wikipedia, а не оригинальные тексты под MIT. При дальнейшем распространении адаптаций сохраняются соответствующие атрибуция, ссылка на лицензию, указание изменений и ShareAlike.

Генерируемый ответ может опираться на эти материалы, но не становится подтверждённым высказыванием Wikipedia. При цитировании и распространении существенных фрагментов сохраняйте их происхождение. Wikimedia и авторы статей не подтверждают качество ответов приложения.

## Apple iTunes Search API

Поиск фильмов без TMDB-токена использует [iTunes Search API](https://performance-partners.apple.com/search-api). Метаданные ссылаются на соответствующую карточку магазина. Содержимое магазина и права на фильмы принадлежат их правообладателям; ответы API не являются открытой библиотекой фильмов.

Промоматериалы Apple регулируются собственными условиями API, включая требования к использованию одобренных магазинных badges и ссылок рядом с соответствующими материалами. FrameTrail не распространяет фильмы, аудио- или видеопревью из этого API. Условия и ссылки магазина нельзя заменять общей лицензией MIT.
