# FrameTrail 1.0.0-beta.1

Первая закрытая бета помощника для фильмов и сериалов. Версия приложения 1.0.0, сборка 1.

- Каталог TMDB с личным API Read Access Token; без ключа доступны сериалы TVmaze и фильмы Wikidata. Отдельное подключение аккаунта TMDB импортирует watchlist.
- Библиотека с просмотренными сериями, обсуждением разрешённых источников, импортом текста/субтитров и подробными сюжетами Wikipedia после просмотра.
- Оценки 1–10 для фильмов, сериалов и отдельных серий. Необязательные вопросы с мультивыбором сюжетных фрагментов, собственными ответами и пропуском.
- Локальная сводка впечатлений по просмотренным сериям: редактирование, сохранение в дневник и системный общий доступ.
- Аккаунты FrameTrail на Supabase, изолированный офлайн-кэш, синхронизация библиотеки и личных записей, явное разрешение конфликтов и удаление аккаунта.
- Дневник со статистикой и отдельными оценками серий; экран памяти с ограниченным кэшем изображений и безопасной очисткой материалов.
- Десять звёзд с выбором тапом или движением пальца, тактильный отклик в значимых действиях, контекстные подсказки и краткий гид в настройках.

## Установка

Загрузите IPA и соседний файл SHA-256. IPA не подписан: AltStore, SideStore или другой совместимый инструмент должен применить вашу подпись. Требуется iOS 26 или новее. В настройках можно добавить свой **TMDB API Read Access Token** без префикса Bearer.

Для генерации нужны совместимое устройство, включённая Apple Intelligence и подготовленная системная модель. Русский использует прямую поддержку модели, если она доступна, либо локальный перевод Apple Translation с установленными пакетами. Весов модели внутри IPA нет.

## Границы беты

Регистрация по email ограничена закрытой бетой владельца, пока в Supabase не подключён собственный SMTP. Подтверждение email обязательно. Диалоги и полные тексты источников остаются на устройстве; сохранённые личные ответы, короткие выбранные фрагменты и сводки синхронизируются.

Источники одной серии исключают другие эпизоды. Wikipedia-пересказ доступен не для каждого произведения; неоднозначные совпадения отклоняются. Ограничение передаваемых материалов не устраняет все возможные ошибки свободной генерации модели. Физическая проверка Foundation Models, задержек, Apple Translation и LiveContainer пока не выполнена.

Релизный процесс проверяет доменные правила, сервисы, хранение данных, пользовательские сценарии на симуляторе и сборку для устройства. Публикация IPA выполняется только после успешных проверок; SHA-256 позволяет проверить целостность файла. Подробности: [README](https://github.com/eljke/FrameTrail#readme).

## English

First closed beta of the native iPhone film and TV companion. Includes optional TMDB search/watchlist connection, episode tracking, post-viewing plot research, title/episode ratings, optional multi-select source-based impressions, on-device series retrospectives, Supabase accounts/sync, a journal and bounded cache management. Generation uses Apple's local system model; Russian may use local Apple Translation. All review fields are optional.

The IPA is unsigned and requires your installation tool to sign it. Minimum iOS: 26. Email confirmation remains enabled; public signup awaits custom SMTP. Physical-device model/translation behavior and LiveContainer compatibility remain unverified. See the [English README](https://github.com/eljke/FrameTrail/blob/main/README.en.md) for setup, source coverage and privacy details.
