# FrameTrail 1.2.0-beta.1

Contract for #13: Series Pulse and native navigation improvements. App 1.2.0, build 3, iOS 26+.

- Checkpoint eligibility is based on explicit watched IDs and season/episode order, never the finished flag. An unknown or unwatched checkpoint produces no episode evidence
- Gaps remain gaps. Later watched episodes, global series plots, foreign-title facts and foreign-title reviews are excluded
- Latest episode reviews are selected before dropping empty cleared records. Whole-show and season reviews cannot leak later events into checkpoint compilations
- Charts show actual ratings only. A picker provides a non-gesture alternative. User notes remain separate from story evidence
- Three explicit local-generation modes use the existing bounded structured source-answer pipeline. Unknown references are rejected; excerpt snapshots remain inspectable
- Account, progress, material, language and glossary changes cancel and invalidate generated content. Nothing is saved automatically
- Library quick resume, native Liquid Glass actions, readable content surfaces and meaningful empty states support the main viewing flow
- RU/EN resources remain aligned. No new dependency, model weights, server or data migration

Acceptance: domain tests for rewind, missing checkpoints and cleared reviews; simulator flow opening Series Pulse with a saved score and impression; existing regression suite; device IPA and published checksum verification. Foundation Models, Translation and LiveContainer require separate physical-device validation.

Expanded scope: local taste patterns and connections use personal reviews, not catalog plots. Recommendations require 7/10, at least 300 movie votes or 150 show votes, and finite popularity metrics. Bayesian weighting reduces small-sample inflation; capped popularity only ranks candidates after eligibility. Model output must resolve to supplied C IDs and valid R review IDs. Already saved titles and shown candidates are excluded; explicit more-picks advances a page through a bounded session. Catalog search supports 25 pages per query; recommendation cache holds four public metadata batches for ten minutes. Personal notes never go to TMDB; seed title identifiers do.
